Installation

Up and running in minutes

Follow these simple steps. No developer knowledge required.

1
Install the module

Copy audit_trail_pro to your addons path, restart Odoo, then go to Settings → Apps and click Install.
2
Configure logging

Go to Audit → Configuration and configure which models and actions to log.
3
Set up alerts

Configure alerts for suspicious activities under Audit → Alerts.
4
View dashboard

Open the dashboard to see real-time audit statistics and high-risk users.

FAQ

Common questions

Everything you need to know before installing.

Will this module slow down my Odoo instance?
No. The module is optimized with PostgreSQL indexes, batch processing, and lazy loading. It has minimal impact on performance.
Is it compatible with Odoo Community and Enterprise?
Yes. The module only depends on base, mail, and web modules and works on both Community and Enterprise editions of Odoo 19.
Can I choose which models to audit?
Yes. The configuration allows you to whitelist or blacklist specific models and fields.
How long are logs retained?
Configurable: 3, 6, 12, or 24 months, or never delete. Automatic cleanup runs via cron job.
Can I export audit logs?
Yes. Export to CSV or Excel with filtering by date, user, model, or action type.
