Installation

Up and running in minutes

Follow these simple steps. No developer knowledge required.

1
Install the module

Copy vdm_product_profitability to your addons path, restart Odoo, then go to Settings → Apps and click Install.
2
Create an analysis

Go to Product Profitability → Profitability Analysis and create a new analysis for a product with date range.
3
Compute margins

Click Compute to calculate sales, costs, and margins automatically.
4
View dashboard and reports

Open the dashboard to see top products and recent analyses. Generate PDF reports for stakeholders.
FAQ

Common questions

Everything you need to know before installing.

Is it compatible with Odoo Community and Enterprise?
Yes. The module only depends on core Odoo apps (sale, account, stock, mail) and works on both Community and Enterprise editions of Odoo 19.
How does it calculate costs?
It uses the product's standard cost from your Odoo inventory valuation. For accurate results, make sure your product costs are up to date.
Can I analyze multiple products at once?
Yes. Create separate analyses for each product or use the dashboard to compare across products and categories.
