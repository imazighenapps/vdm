Installation

Up and running in minutes

Follow these simple steps. No developer knowledge required.

1
Install the module

Copy vdm_construction_time_tracker to your addons path, restart Odoo, then go to Settings → Apps and click Install.
2
Create your first worker

Go to Construction Time → Workers and add your team members with their hourly rates and skills.
3
Set up project phases

Create phases under Construction Time → Project Phases to organize your work.
4
Start logging time

Create time entries and watch the dashboard update in real-time.
5
Generate reports

Use the reporting menu to generate PDF time entries, daily summaries, and cost analysis reports.
FAQ

Common questions

Everything you need to know before installing.

Is it compatible with Odoo Community and Enterprise?
Yes. The module only depends on core Odoo apps (project, hr, mail, account) and works on both Community and Enterprise editions of Odoo 19.
Can I customize the hourly rates?
Yes. Each worker has their own configurable hourly rate. Equipment and subcontract rates can be set globally in Configuration.
Does it work with the Construction Tracker module?
Yes! Both modules are designed to work together. You can use Construction Tracker for BOQ, site diaries, and billing, while Time Tracker handles all time tracking needs.
How many users can use it simultaneously?
All Odoo users with the Construction Time / User role can log time simultaneously. The dashboard updates in real-time for all users.
