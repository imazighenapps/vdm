User Manual

Step-by-step guide to get the most out of Construction Project Tracker

1

Installation

  1. Download the module zip from the Odoo Apps Store.
  2. Extract vdm_construction_tracker into your Odoo addons directory.
  3. Restart the Odoo server.
  4. Go to Apps → Update Apps List.
  5. Search Construction Project Tracker → Install.
✅ Dependencies (project, purchase, stock, account, hr, mail) install automatically.
2

Create a Project

  1. Construction → Projects → All Projects → New.
  2. Fill: Project Name, Client, Site Manager.
  3. Set Contract Value, Start Date, End Date.
  4. Choose Project Type: Residential, Commercial, Industrial, Infrastructure, Renovation.
  5. Click Confirm to activate.
✅ Auto-generated reference: PRJ-0001, PRJ-0002, etc.
3

Set Up Bill of Quantities (BOQ)

  1. From project, click BOQ smart button → New.
  2. Add lines: Description, Work Type, Unit, Qty, Rate.
  3. Amount auto-calculated (Qty × Rate).
  4. Link lines to Phases for progress tracking.
  5. Click Approve when finalized.
✅ Create revisions of approved BOQs. Revision number auto-increments.
4

Daily Progress Reports (DPR)

  1. Construction → Site Management → Daily Reports → New.
  2. Set Date, Weather, Temperature.
  3. Describe Work Completed in rich text.
  4. Enter Labor, Materials, Machinery.
  5. Record Safety Issues and Delay Reasons.
  6. Write Next Day Plan.
  7. Select Phases Worked Today to link to phases.
  8. Click Submit for approval.
5

Site Photos with Geolocation

  1. In a DPR, go to Photos tab → Add a line.
  2. Upload photo, add Caption, select Photo Type (Progress, Quality, Safety, Issue, General).
  3. Enter Latitude and Longitude for GPS tracking.
6

RA Billing (Running Account)

  1. Construction → Billing → RA Billing → New.
  2. Select project, enter Billing Period.
  3. Add lines with descriptions, quantities, rates.
  4. Set Retention % (default 5%), Advance Recovery.
  5. Net Payable auto-calculated.
  6. Submit → Approve → Create Invoice.
✅ Create Invoice generates a customer invoice in Accounting automatically.
7

Change Orders

  1. Construction → Billing → Change Orders → New.
  2. Describe the change and select Reason (Client Request, Design Change, Site Condition, Regulation, Error, Other).
  3. Enter Original Amount and Variation Amount.
  4. New Total auto-calculated.
  5. Submit → Approve → Implement.
⚠️ Pending change orders appear as alerts on the dashboard.
8

Subcontractor Management

  1. Construction → Subcontracts → New.
  2. Fill: Subcontractor, Scope, Contract Value, Retention %.
  3. Activate to start tracking.
  4. Record measurements in Measurements tab.
  5. Amount Paid and Remaining auto-tracked.
9

OWL 3 Dashboard

  1. Construction → Dashboard.
  2. Stats cards: Total Projects, Active, Contract Value, Avg Progress.
  3. Quick Actions: Jump to Projects, DPR, BOQ, Billing, Changes, Subcontracts.
  4. Alerts: Overdue projects and pending approvals highlighted.
  5. Recent Projects table with progress bars. Click to open.
10

PDF Reports

  • BOQ Report: Open BOQ → Print → BOQ Report
  • DPR Report: Open DPR → Print → Daily Progress Report
  • RA Billing Report: Open Billing → Print → RA Billing Report
11

Tips & Best Practices

  • Start with the Dashboard — overview and alerts at a glance.
  • Submit DPRs daily — consistent records prevent disputes.
  • Use phase weights — assign weights for accurate progress %.
  • Link BOQ to phases — auto-progress from work orders.
  • Capture photos regularly — invaluable for disputes.
  • Review change orders weekly — dashboard alerts you.
  • Use Print for PDFs — ready for client meetings.
  • Multi-company — each company sees only its projects.
