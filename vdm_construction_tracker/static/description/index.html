User Manual

Step-by-step guide

Everything you need to get started, from installation to daily usage.

1
Install the module

Copy vdm_construction_tracker to your addons path, restart Odoo, then go to Apps and click Install.
2
Create a Project

Go to Construction → Projects → All Projects → New. Fill in: Project Name, Client, Site Manager, Contract Value, Start Date, End Date. Click Confirm.
3
Set Up BOQ & Phases

Click the BOQ smart button → New. Add lines with Description, Work Type, Unit, Qty, Rate. Link to phases for progress tracking. Click Approve.
4
Submit Daily Reports

Go to Site Management → Daily Reports → New. Fill weather, work completed, labor, materials. Add photos with GPS. Click Submit.
5
Create RA Billing

Go to Billing → RA Billing → New. Add lines, set retention %, advance recovery. Submit → Approve → Create Invoice.
6
Manage Change Orders

Go to Billing → Change Orders → New. Describe change, select reason, enter amounts. Submit → Approve → Implement.
7
Track Subcontracts

Go to Subcontracts → New. Fill subcontractor, scope, contract value, retention %. Activate and record measurements.
8
Use the Dashboard

Go to Construction → Dashboard. View stats, alerts for overdue projects, quick actions. Click any project to open.

FAQ

Common questions

Everything you need to know before installing.

Does this module work with Community edition?
Yes. The module works on both Odoo 19 Community and Enterprise editions. No Enterprise-specific features are required.
Is my project data secure?
Absolutely. No external APIs are called. All data stays on your Odoo server. The module has zero external dependencies.
Can I customize the module?
Yes. The module follows standard Odoo conventions. You can extend models, add views, create custom reports, and adapt it to your workflow.
How many users can use it simultaneously?
All users with the Construction User role can use the module. Concurrency is limited only by your Odoo server capacity.
