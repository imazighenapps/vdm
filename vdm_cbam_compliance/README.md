# CBAM Compliance Tracker for Odoo 19

## Overview
EU Carbon Border Adjustment Mechanism (CBAM) compliance module for Odoo 19.
Track embedded emissions, manage certificates, and file quarterly CBAM reports.

## Features
- CBAM product categorization (6 sectors)
- Import event tracking with automatic emission calculation
- Certificate purchase and surrender management (FIFO)
- Quarterly report generation (CSV/PDF)
- EU default emission values
- Dashboard with compliance overview

## Installation
1. Copy `vdm_cbam_compliance` to your Odoo addons path
2. Update the Apps list
3. Install **CBAM Compliance Tracker**

## Configuration
1. Go to CBAM > Configuration > CBAM Products
2. Mark products as CBAM-covered and set embedded emissions
3. Configure suppliers with emission data
4. Start recording import events

## Supported Sectors
- Cement
- Iron & Steel
- Aluminium
- Fertilizers
- Electricity
- Hydrogen
