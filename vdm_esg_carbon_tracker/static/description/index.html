FAQ

Frequently Asked Questions

Does this replace Odoo's native ESG module?
No. This module extends Odoo's ESG capabilities with advanced carbon accounting features including CSRD/ESRS E1 compliance, reduction targets, carbon offset management, and anomaly detection. It works alongside the native module.
Is this compatible with CSRD reporting requirements?
Yes. The module is designed to align with EU CSRD and ESRS E1 climate disclosure standards. It provides the data structure needed for compliant reporting.
Which emission factor databases are supported?
The module ships with DEFRA emission factors pre-loaded. You can import factors from EPA, ecoinvent, ADEME, and GHG Protocol databases. Custom emission factors are also supported.
Can I set science-based targets?
Yes. The module supports SBTi-aligned target setting with 1.5°C, well-below-2°C, and custom scenarios. Track progress against base year and interim milestones.
